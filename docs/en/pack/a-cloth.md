# Arcomua Cloth

## Introduction

Arcomua Cloth is a modpack whose primary goal is to optimize game performance while enhancing vanilla gameplay and adding many small utility features. It is suitable for vanilla survival and server players. While enriching the player experience, it also pursues better performance.
