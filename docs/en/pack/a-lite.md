# Arcomua Lite

:::warning Warning
The Lite edition is no longer under development or maintenance.
:::

## Introduction

Arcomua Lite is a modpack that highly optimizes vanilla gameplay. It is suitable for vanilla survival and server players seeking maximum performance. While pursuing better performance, it keeps vanilla gameplay as unchanged as possible and provides a comfortable gameplay experience.
