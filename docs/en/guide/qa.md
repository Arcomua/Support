# Troubleshooting

This article covers various common issues. Use the site's search function or your browser's built-in page search to quickly find questions and solutions. If something is missing from this article, feel free to submit a Pull Request to improve it.

## How do I close the information box in the upper-left corner?

Press the H key on your keyboard to close it.

## Is there a tree-chopping mod?

This modpack does not include a tree-chopping mod. Install one yourself if needed.

## The game crashes after I add or remove some mods

Unless you know what you are doing, please do not modify the modpack arbitrarily.

You can describe the issue in the group chat in detail. Someone may be able to help, but help is not guaranteed.

## It does not work on mobile phones

We have no plans to make this modpack compatible with mobile devices.

## Is there a server pack?

Arcomua Modpacks are vanilla-based modpacks. You can start a server using a vanilla server implementation such as Paper.

If you choose to use a Fabric server, consider using [Relentleserver](https://modrinth.com/modpack/relentleserver).

## I cannot open Modrinth

Try switching to a different network environment. For example, if Modrinth does not open while you are connected to Wi-Fi, try switching to a mobile hotspot and trying again. You can also try using a VPN.

The level of blocking applied to foreign websites varies by region. If you still cannot download the modpack, you can get it from the files in our QQ group or from our official website.

## How do I install it in the official launcher?

The official launcher does not support managing third-party content, such as downloading from mirror sources or installing mod loaders. Therefore, we strongly recommend against using it.

We recommend using HMCL, PCL2, or BakaXL instead. Third-party launchers make it easier to install modpacks.

## How do I enable the block information display at the top of the game screen?

Press the 1 key on the numeric keypad to enable the block information display.

We usually remove its key binding to prevent it from being closed accidentally. If you want to disable it, go to “Options” > “Controls” > “Key Binds”, find the “Jade” category, and assign a key to “Show Overlay” or reset its key binding. Then press the assigned key in-game to disable it.

## The log is taking up too much space / The game will not open (one possible cause)

In Task Manager, find RivaTuner Statistics Server (RTSS), right-click it, and select “Open file location”. In the File Explorer window that appears, find `uninstall.exe` and double-click it to completely uninstall RTSS. If it cannot be uninstalled, select RTSS first and click “End task”.

Sodium is incompatible with RTSS, while Sodium is an important optimization mod in the modpack. Therefore, one of them has to be removed.

## How do I change the crosshair back to the vanilla style?

Open the modpack's `mods` folder and delete Dynamic Crosshair and Dynamic Crosshair Compact, if present.

## A red circle appears after I click coordinates in the chat. How do I remove it?

Press the C key to clear the coordinate highlight.

## What should I do when “Controlify Native Libraries” and similar messages appear the first time I open the game?

If you want to play with a controller, click “Yes”. Otherwise, click “No”.
