# Installing the Modpack with BakaXL

This guide will show you how to install Arcomua Modpack using BakaXL.

## Download the Launcher

[Click here](https://www.bakaxl.com/) to go to the launcher download page.

You can find detailed information about the launcher in the [BakaXL Documentation Center](https://help.bakaxl.com/). This guide focuses only on installing the modpack.

This guide uses BakaXL 3.5.1.0.

## Online Installation

1. When using BakaXL for the first time, follow the launcher wizard to complete the launcher setup.

2. After reaching the launcher home page, click “Switch Minecraft Game Core”.

   ![BakaXL Home Page](https://raw.githubusercontent.com/Arcomua/Support/refs/heads/assets/BakaXL/BakaXL-Step1.png)

3. Click “Try to Get and Install This Version”, then click “Yes” in the dialog box. After switching pages, click “Get Popular Modpacks” in the left sidebar.

4. After entering BakaXL's modpack marketplace, enter “Arcomua” in the search bar in the upper-right corner and click “Search for This Keyword on Modrinth”.

   ![BakaXL Modpack Marketplace](https://raw.githubusercontent.com/Arcomua/Support/refs/heads/assets/BakaXL/BakaXL-Step2.png)

5. Click the modpack you want to download. On the details page, click the download button in the upper-right corner. Use the filter on the left to select the desired game version. In the version list on the right, select the top entry (the top entry is usually the latest version), click “Download and Install” to the right of the entry, and click “Yes” in the dialog box that appears.

   ![BakaXL Downloads](https://raw.githubusercontent.com/Arcomua/Support/refs/heads/assets/BakaXL/BakaXL-Step3.png)

6. The modpack is now downloading in the background. Please wait. After the installation is complete, click the button in the upper-left corner to return to the home page.

7. Normally, you can launch Arcomua Modpack from the launcher at this point. If the game core is still empty, you need to install it manually.

8. Return to the “Add New Minecraft Instance or Modpack” page, click “Import Modpack” in the left sidebar, and click “Continue”.

9. Open File Explorer on your computer and find the folder named `BakaXL` located in the same folder as the BakaXL launcher. Open the `Temp` folder inside it.

10. This folder contains the modpack installation files downloaded from the modpack marketplace. Click and drag the file into the BakaXL launcher, then wait for the launcher to complete the modpack installation.

    ![BakaXL Manual Installation](https://raw.githubusercontent.com/Arcomua/Support/refs/heads/assets/BakaXL/BakaXL-Step4.png)

:::info Tip
If you encounter other issues while using BakaXL, please consult the [BakaXL Documentation Center](https://help.bakaxl.com/) first.
:::
