# Installing the Modpack with PCL2

This guide will show you how to install Arcomua Modpack using PCL2.

## Download the Launcher

[Click here](https://afdian.com/p/0164034c016c11ebafcb52540025c377) to go to the launcher download page.

You can find detailed information about the launcher in the [PCL Help Library](https://github.com/LTCatt/PCL2Help). This guide focuses only on installing the modpack.

This guide uses PCL Release 2.10.6.

## Online Installation

1. If you are using PCL2 for the first time, log in to an account or add an offline account on the launch page.

   ![PCL2 Home Page](https://raw.githubusercontent.com/Arcomua/Support/refs/heads/assets/PCL2/PCL2-Step1.png)

2. Click “Download” in the top navigation bar, then click “Modpacks” in the left sidebar. Enter “Arcomua” in the name field.

   ![PCL2 Downloads](https://raw.githubusercontent.com/Arcomua/Support/refs/heads/assets/PCL2/PCL2-Step2.png)

3. Find the modpack you want to download. On the details page, select a Minecraft version and expand the corresponding entry. Select the top entry in the drop-down menu (the top entry is usually the latest version). In the dialog box that appears, click “Confirm”.

   ![PCL2 Installation](https://raw.githubusercontent.com/Arcomua/Support/refs/heads/assets/PCL2/PCL2-Step3.png)

4. The modpack is now downloading in the background. Please wait. After the installation is complete, click the button in the upper-left corner to return to the home page.

5. You can now click “Launch Game” to start Arcomua Modpack.

:::info Tip
If you encounter other issues while using PCL2, please consult the [PCL Help Library](https://github.com/LTCatt/PCL2Help) first.
:::
