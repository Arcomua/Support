# Installing the Modpack with PCL2 Community Edition

This guide will show you how to install Arcomua Modpack using PCL2 Community Edition.

## Download the Launcher

[Click here](https://github.com/PCL-Community/PCL2-CE/releases) to go to the launcher download page.

You can find detailed information about the launcher in the [PCL Community Edition Help Library](https://github.com/PCL-Community/PCL2CEHelp). This guide focuses only on installing the modpack.

This guide uses PCL2-CE Release 2.12.3.
